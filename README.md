# To Be Clad — Конструктор образов

Онлайн-конструктор образов в стиле бумажных кукол. Собери аутфит на манекене, настрой цвета через RGB-палитру и сохрани свои лучшие комбинации!

## Функционал

- **Аккаунты** — регистрация и авторизация (JWT), сброс пароля
- **Главная страница** — детский дизайн в стиле бумажных кукол
- **Конструктор образов** — манекен с 4 зонами (голова, торс, ноги, обувь), выбор одежды + настройка цвета через палитру RGB, перемещение/поворот/масштаб
- **Сохранённые образы** — страница с сохранёнными образами, редактирование и переименование
- **Админ-панель** — управление категориями и элементами одежды (добавление/удаление/скрытие), создание новых зон, импорт SVG
- **SVG шаблоны** — перекрашиваемые SVG-элементы одежды с мульти-зонной раскраской
- **Страница контактов** — форма обратной связи и описание сайта

## Технологии

- **Frontend:** React + Vite + TypeScript
- **Backend:** Node.js + Express + TypeScript
- **БД:** SQLite (Prisma ORM)
- **Авторизация:** JWT (bcryptjs + jsonwebtoken)
- **Цвет:** react-colorful

## Запуск

```bash
# Установка зависимостей
cd server && npm install
cd ../frontend && npm install

# Инициализация БД и запуск backend (порт 3001)
cd ../server
npx prisma generate
npx prisma db push
npx tsx src/index.ts
# При первом запуске БД автоматически заполняется данными (32 элемента одежды, аккаунты admin и demo)

# Запуск frontend (порт 5173, в другом терминале)
cd ../frontend
npx vite
```

> **Деплой:** При первом запуске сервер автоматически заполняет пустую БД данными (одежда, аккаунты). Не нужно запускать сид вручную — просто разверните и запустите.

## Заготовки одежды (SVG)

SVG-шаблоны используют маркеры `FILL_COLOR_1`, `FILL_COLOR_2`, `FILL_COLOR_3` для мульти-зонной раскраски. Для добавления новых элементов через админ-панель:

1. Создайте SVG с `viewBox`
2. Используйте `FILL_COLOR_1`, `FILL_COLOR_2`, `FILL_COLOR_3` вместо конкретных цветов заливки
3. Вставьте SVG-код в поле "SVG шаблон" при добавлении элемента

### Ресурсы для SVG заготовок

- [Freepik](https://www.freepik.com) — бесплатные SVG иллюстрации одежды
- [Flaticon](https://www.flaticon.com) — иконки одежды в SVG
- [SVGRepo](https://www.svgrepo.com) — коллекция бесплатных SVG
- [OpenGameArt](https://opengameart.org) — спрайты и арт для игр

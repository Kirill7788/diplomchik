# OutfitLab — Конструктор образов

Pinterest-стиль конструктор образов с возможностью собрать аутфит на манекене, настроить цвета через RGB-палитру и сохранить свои лучшие комбинации.

## Функционал

- **Аккаунты** — регистрация и авторизация (JWT)
- **Главная страница** — описание сервиса
- **Конструктор образов** — манекен с 3 зонами (голова, торс, ноги), выбор одежды + настройка цвета через палитру RGB
- **Сохранённые образы** — страница с сохранёнными образами и отдельными элементами
- **Админ-панель** — управление категориями и элементами одежды (добавление/удаление/скрытие)
- **SVG шаблоны** — перекрашиваемые SVG-элементы одежды

## Технологии

- **Frontend:** React + Vite + TypeScript
- **Backend:** Node.js + Express + TypeScript
- **БД:** SQLite (Prisma ORM)
- **Авторизация:** JWT (bcryptjs + jsonwebtoken)
- **Цвет:** react-colorful

## Запуск

```bash
# Установка зависимостей
cd server && npm install
cd ../frontend && npm install

# Инициализация БД
cd ../server
npx prisma generate
npx prisma db push
npx tsx src/seed.ts

# Запуск backend (порт 3001)
npx tsx src/index.ts

# Запуск frontend (порт 5173, в другом терминале)
cd ../frontend
npx vite
```

## Заготовки одежды (SVG)

SVG-шаблоны используют маркер `FILL_COLOR`, который заменяется на выбранный цвет. Для добавления новых элементов через админ-панель:

1. Создайте SVG с `viewBox`
2. Используйте `FILL_COLOR` вместо конкретного цвета заливки
3. Вставьте SVG-код в поле "SVG шаблон" при добавлении элемента

### Ресурсы для SVG заготовок

- [Freepik](https://www.freepik.com) — бесплатные SVG иллюстрации одежды
- [Flaticon](https://www.flaticon.com) — иконки одежды в SVG
- [SVGRepo](https://www.svgrepo.com) — коллекция бесплатных SVG
- [OpenGameArt](https://opengameart.org) — спрайты и арт для игр
